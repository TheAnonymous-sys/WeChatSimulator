# 微信模拟器页面与交互结构

本文件用于约束模拟器的页面归属、跳转和数据状态。视觉以实际安卓微信截图为准；外部原型仅用于核对层级和流程，不直接照搬旧版样式。

## 1. 应用外壳

应用外壳只负责四类固定区域：

1. 系统状态栏；
2. 当前页面标题栏；
3. 页面内容区；
4. 四项底部导航。

底部导航只对应四个一级页面：`微信`、`通讯录`、`发现`、`我`。进入聊天详情、联系人资料、朋友圈等二级页面后，底部导航隐藏，标题栏显示返回按钮。

## 2. 一级页面

### 微信

- Windows 登录提示属于列表上方的系统状态条，不是会话。
- 会话是统一实体，单聊、群聊、公众号和文件传输助手只是在类型上不同。
- `置顶` 是会话状态：所有置顶会话自动排在普通会话之前，并使用较深的灰色背景；置顶会话内部保持用户设置的顺序。
- `未读` 与 `免打扰` 是两个独立状态：普通未读显示数字，免打扰未读显示红点并在摘要右侧显示静音图标。
- 点击会话进入共用的聊天详情页。
- 长按会话打开操作菜单，不进入新页面。

### 通讯录

- 顶部固定入口：新的朋友、仅聊天的朋友、群聊、标签、公众号、服务号。
- 下方联系人按分组和字母索引排列。
- 点击联系人进入联系人资料页；从资料页点击“发消息”再进入共用聊天详情页。
- 通讯录不是微信会话列表的子页面，两者是并列一级页。

### 发现

- 发现页只是功能入口集合。
- 朋友圈、看一看等均为二级页面。
- 朋友圈内部再包含动态详情、评论操作、图片查看、发布动态等后续页面或浮层。

### 我

- 顶部资料卡进入个人信息页。
- 服务、收藏、朋友圈、作品、卡包、表情和设置均为二级入口。
- 设置内部可以继续进入账号、安全、通用等三级页面。

## 3. 共用二级页面

下列页面可以从多个入口到达，不应复制为不同页面：

- 聊天详情：可从会话列表、联系人资料或搜索结果进入；
- 联系人资料：可从通讯录、群成员或聊天信息进入；
- 图片查看器：可从聊天图片、朋友圈或收藏进入；
- 搜索结果：由全局搜索进入，再跳转至会话、联系人或内容详情。

返回操作应回到实际来源页面，而不是写死返回某个底栏页。

## 4. 浮层与临时状态

以下内容不是独立页面：

- 右上角“＋”菜单；
- 会话长按菜单；
- 消息长按菜单；
- 表情、更多功能和语音输入面板；
- 红包、转账等确认弹窗；
- 删除、撤回等确认对话框。

这些内容关闭后应保留原页面及滚动位置。

## 5. 模拟器自身的数据分层

- `content`：用户填写的人物、会话、消息、朋友圈和个人资料；
- `uiState`：当前一级页、导航栈、滚动位置和已展开的浮层；
- `appearance`：安卓状态栏、字号、主题和系统提示条；
- `editorState`：编辑面板当前选中的对象，仅用于制作界面，不属于模拟微信本身。

后续新增页面必须先确定属于一级页、共用二级页还是浮层，再实现跳转，避免把所有内容平铺在同一层。
